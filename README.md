# SGDOX – Sistema de Gestión Documental para Ecuador

![SGDOX Logo](LOGO-SGDOX.png)

**SGDOX** es una plataforma integral de **gestión documental electrónica, firma electrónica y administración de expedientes**, desarrollada en Ecuador por **Floydu S.A.S.**

Está orientada a instituciones públicas y privadas que necesitan controlar formalmente sus documentos, comunicaciones institucionales, trámites, expedientes, usuarios, firma electrónica, trazabilidad y procesos administrativos.

SGDOX permite gestionar en una sola plataforma la **elaboración, revisión, firma, envío, recepción, reasignación, seguimiento, búsqueda, archivo, auditoría y organización documental**, integrando además expedientes con **Número Único de Trámite (NUT)**, ventanilla, ciudadanos y administración institucional.

SGDOX nace como una **alternativa moderna a Quipux y otros sistemas de gestión documental heredados**, diseñada para las necesidades actuales de instituciones ecuatorianas.
